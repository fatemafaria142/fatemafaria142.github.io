# fatemafaria142.github.io

Personal academic homepage, built on the [academic-homepage](https://github.com/luost26/academic-homepage) Jekyll template.

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

## Content

- `_data/profile.yml` — bio, positions, education, experience, awards, social links
- `_news/` — one file per news item
- `_publications/` — one file per publication, grouped by year
